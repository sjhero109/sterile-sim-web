# 무균 생산라인 공정 시뮬레이터 (웹 버전)

`index.html` 한 파일로 된 시뮬레이터입니다. 내려받아 더블클릭하면 브라우저에서 바로 열립니다(설치 불필요).

- 탭 1 · 자동화로봇 설비 구동 — 라인 전체 3D(로봇·트레이·자재 흐름)
- 탭 2 · 가압 건조 — 모드 B 공기흐름(격자 유동해석), 트레이별 건조 곡선
- 탭 3 · CIP 세척 — 스프레이볼 물줄기·유막·드레인, 오염 세척 과정
- 탭 4 · VHP/에어레이션 — 증기 순환·확산, 압축공기 에어레이션

권장 브라우저: 최신 Chrome / Edge. 모바일에서도 볼 수 있습니다.

> 이 저장소에는 빌드된 시뮬레이터(HTML)만 있습니다. 원본 소스와 설비 자료는 비공개입니다.
