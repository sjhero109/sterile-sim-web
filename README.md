# 무균 자동화 로봇 설비 시뮬레이터 (웹 버전)

`index.html` 한 파일로 된 시뮬레이터입니다. 내려받아 더블클릭하면 브라우저에서 바로 열립니다(설치 불필요).

- 무균 자동화 로봇 설비 — 라인 전체 3D(로봇 12대·트레이·몰드가 자리와 자재 기준으로 움직임, 레일 카메라)
- 가압 건조 — 모드 B 공기흐름(격자 유동해석), 트레이별 건조 곡선, 권장 대류건조 시간 범위
- CIP 세척 — 스프레이볼 물줄기·벽을 타고 퍼지는 물막·드레인, 오염 세척 과정
- VHP/에어레이션 — 증기 순환·확산, 압축공기 에어레이션, 권장 드웰 시간·사이클 수

레시피: 홈페이지에 저장된 공용 레시피를 각 화면의 목록에서 골라 적용합니다. 레시피 추가·삭제는 상단 우측 "관리자 접속"에서만 할 수 있습니다.

권장 브라우저: 최신 Chrome / Edge. 모바일에서도 볼 수 있습니다.

> 이 저장소에는 빌드된 시뮬레이터(HTML)만 있습니다. 원본 소스와 설비 자료는 비공개입니다.
